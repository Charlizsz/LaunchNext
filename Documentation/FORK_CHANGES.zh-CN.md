# Charlizsz 分支改动说明

## 2.4.2-C（2026-10-21）

- 放宽应用名称的可用宽度，利用图标间的空隙延后换行；当前布局下 Tampermonkey 可保持单行，较长名称仍最多显示两行。字号、图标位置及动画保持不变。
- 设置中的图标大小显示实时百分比（保留一位小数），方便记住和还原比例。
- 应用版本统一为 `2.4.2-C`（构建号 `20261021`）。更新检查、Swift 更新器和 Python 更新器均改为 `Charlizsz/LaunchNext`，避免更新到上游版本覆盖定制功能；版本比较支持后续 `-C.1` 等修订号。
- 本地构建同步编译 Swift 更新器，并从项目配置写入版本号，避免沿用旧更新器或旧版本元数据。
- 支持 ChatGPT 客户端选择的 Codex 等图标：读取客户端的图标偏好和对应资源。
- 支持 Telegram 自选图标：读取应用已写入的 Finder 自定义图标资源，不读取聊天数据库，不修改 Telegram 文件。
- 自选图标用于应用网格及文件夹缩略图；重新打开 LaunchNext 时检查选择变化并刷新缓存，资源不可用时回退到默认图标。
- 验证：完整本地编译、严格签名和安装检查通过；名称显示、百分比、自选 ChatGPT/Codex 图标及 Telegram 粉紫渐变图标已在本机确认，并由实际使用确认效果。资源解析边界及 C 版本比较已通过定向检查；未进行完整 Xcode/Intel 构建或公证。

下载：[2.4.2-C Release](https://github.com/Charlizsz/LaunchNext/releases/tag/v2.4.2-C)（Apple Silicon，macOS 26 及以上，ad-hoc 签名）。

## 2026-10-21：文件夹可见边界修复（第三版发行）

- 文件夹内图标的命中检测先检查网格可见区域和文件夹圆角边界，再判断图标位置。
- 修复底部图标被裁掉的部分仍可在文件夹外触发悬停放大的问题；移出可见区域时清除悬停状态。
- 文件夹动画期间不允许交互时同步清除悬停状态；保留原有拖出文件夹逻辑。
- 验证：被裁剪的下半部分、圆角外侧及视口外坐标不命中，可见图标区域正常命中；编译、签名检查及本机安装通过，问题已由实际使用确认解决。

## 2026-10-21：清晰度优化（第二版发行）

- 取消首页与文件夹内文字、图标的额外图层栅格化，减少二次位图缩放造成的模糊。
- 静止网格及图标对齐屏幕像素；文字仅对齐位置，保留原有标签宽度，避免改变临界长度名称的换行。
- 统一使用显式像素尺寸生成图标：首页与文件夹按实际显示尺寸和屏幕倍率渲染，避免 `lockFocus` 隐式倍率叠加。
- 首页图标缓存区分尺寸与屏幕倍率，并在窗口显示倍率变化时重新生成图层。
- 保留现有列数、间距、字号及文件夹展开/收起动画流程。
- 验证：1×/2× 图标位图尺寸检查、完整编译、严格签名检查、本机安装与首页/文件夹显示检查均通过；清晰度改善已由实际使用确认。

## 2026-10-21：布局、文件夹与交互优化

本轮改动基于 LaunchNext 2.4.2，保留原项目及其 GPL-3.0 许可。以下内容为本分支的定制改动，不代表上游发布说明。

### 应用名称与主界面布局

- 应用名称最多显示两行；超过两行仍使用省略号，避免挤占相邻图标。
- 略微缩小图标与应用名称之间的距离，并统一相关布局计算。
- 调整窗口模式下单页主界面的底部留白，使其与顶部搜索栏区域更协调。
- 同步调整搜索框与下方图标网格之间的间距。

### 文件夹布局设置

在设置的外观相关区域增加独立的文件夹布局选项：

| 设置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 每行图标数量 | 6 | 3–8 |
| 文件夹内图标大小 | 80 pt | 40–128 pt |
| 文件夹内图标行间距 | 10 pt | 0–40 pt |

- 文件夹内图标大小独立于首页；空间不足时按列宽限制实际尺寸，防止重叠。
- 新设置支持保存、重新加载、导入导出和恢复默认值。
- 缩小文件夹顶部、名称及第一行图标之间的间隙。
- 文件夹缩略图中的每个小图标宽高减少 1 pt，保持中心位置不变。

### 设置窗口与滚动

- 设置改为独立、可拖动和调整大小的原生窗口，便于一边修改一边观察主界面。
- 保持设置窗口与主界面的外观和窗口层级同步，并记忆设置窗口位置。
- 文件夹内容超出可视范围时使用原生覆盖式滚动条；滚动时显示，空闲时自动隐藏。
- 滚动条沿文件夹内侧边缘定位：纵向贴右侧、横向贴底部，保留约 4 pt 间隙，两端各留 24 pt 避开圆角，不占用图标网格空间。
- 使用独立原生覆盖层承载滚动条，避免被 SwiftUI 内容遮挡；滚轮事件转交文件夹网格，覆盖层空白区域不拦截图标操作。
- 修复单页文件夹因底部空白而仍可上下滚动的问题；多页或超高内容仍可正常滚动。

### 文件夹交互与动画

- 文件夹打开时，背景首页图标停止响应悬停放大，并清除已有的悬停状态；关闭后恢复。
- 从准备阶段隐藏正式图标网格，避免展开前提前显示全部图标。
- 动画图标使用与文件夹边界同步的动态裁切，避免展开时越界闪现。
- 展开时，应用名称与对应图标共用移动、缩放和透明度动画。
- 收起时只保留图标动画，不将应用名称缩入文件夹缩略图，消除小字闪动。

### 不安装完整 Xcode 的本地构建

新增 `scripts/local-build/` 和[本地构建说明](LOCAL_BUILD.md)，支持在已验证的 Apple Silicon / Command Line Tools 环境中构建。此方式复用已安装应用的编译资源，生成 ad-hoc 签名的本地版本，不是独立的发行打包或公证流程。
